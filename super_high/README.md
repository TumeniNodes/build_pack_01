# Super High Fences (`super_high`)

A standalone boundary expansion for **Minetest Game / Luanti**, created by **TumeniNodes**. Part of the `build_pack_01` collection.

This mod introduces heavy-duty, triple-height (3-node tall) fence panels and corner columns. It is designed specifically to be used for fortresses, high-security compounds, industrial shipyards, and keep perimeters.
The straight panels can also be used as windows, and they set/place into the straight arch nodes.
The intended way to set/place these nodes is to aim one node above where you want the bottom to sit, this means in order to place a fence node next to another, you need to aim half way up the side of the existing fence node.
This seems difficult, but with time it becomes like second nature.

## Features

* **Tall Nodeboxes:** Renders sleek, 3-meter tall flat panels spanning a single block layer.
* **Corner Nodes:** Includes specialized 90-degree Corner Panels and Inside Corner (ICorner) brackets to stop gaps at boundary intersections.
* **Materials:** Old Wood, Wrought Iron, Structural Steel, and Rusted Iron.

## Installation

Ensure this folder is placed inside your world's `mods/` directory or parent modpack folder and named exactly `super_high`.
