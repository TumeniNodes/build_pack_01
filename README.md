# Build Pack 01

A comprehensive architectural expansion modpack for **Minetest Game / Luanti**, created by **TumeniNodes**. 

This pack decomposes heavy structural designs into highly customizable, standalone building components. Every mod inside this pack is completely self-contained and features fully integrated survival crafting recipes.

## Featured Modules

### 🏛️ Arches (`arches`)
Adds detailed nodebox arch shapes and complex intersection pieces (Two-Way, Three-Way, and Four-Way variants). 
* **Materials:** Brick, Clay, Cobble, Mossy Cobble, Stone variants, Sandstone variants, and all default wood types.

### 🧱 Thin Walls (`thin_walls`)
Adds thin partition walls designed to optimize indoor room division without wasting full-block spaces. Includes transitions from full-height to half-height walls.
* **Materials:** Brick, Clay, Cobble, Mossy Cobble, Stone variants, Sandstone variants, and all default wood types.

### 🚧 Super High Fences (`super_high`)
Adds triple-height (3-node tall) heavy-duty flat walls, corner fences, and interior corner pieces designed for strongholds, boundaries, and industrial yards.
* **Materials:** Old Wood, Wrought Iron, Steel, and Rusted Iron.

### 🚪 Single Arch Doors (`single_arch_doors`)
Engineered specifically to fit seamlessly underneath your single-arch shapes. Features intermediate physical collision tracking frames for realistic opening and closing animation delays.
* **Styles:** Castle Door (Wood/Steel) and Dungeon Door (Iron/Steel). Includes standard and flush-centered layout variants.

## Installation

1. Download the modpack folder.
2. Ensure the top-level directory is named exactly `build_pack_01`.
3. Move `build_pack_01` into your Minetest `mods/` directory.
4. Enable the modpack (or select individual modules) in your world configuration menu.

## Dependencies

* `default` (Found in Minetest Game / Luanti core)
